AVANCY COLLECTIVES V5.3 FINAL

This package is a complete merged project based on the V4 backend plus the streetwear V5 UI.

Included:
- Product CRUD + Cloudinary upload
- Neon PostgreSQL schema auto-creation
- Admin authentication and dashboard
- Admin order management with status updates
- Customer accounts, profile and order history
- Saved addresses with FULL NAME
- Order tracking by order number + checkout email
- Download invoice from account orders, tracking and admin order management
- Search overlay and shop search
- CREATE YOURS custom print builder; custom pieces enter the same cart/checkout flow
- COD checkout
- Razorpay checkout when RAZORPAY_KEY_ID and RAZORPAY_KEY_SECRET are configured
- Verified Razorpay signature handling
- Payment-success page with automatic 5-second redirect to Thank You
- Instagram and YouTube footer links only; TikTok and FAQ removed from primary navigation

Existing .env.local is not included for security. Keep your existing DATABASE_URL, Cloudinary and admin variables.
For Razorpay online payments set RAZORPAY_KEY_ID and RAZORPAY_KEY_SECRET.
